# React Responsive Pagination

An accessible, responsive React pagination component that fits the width available to it: it shows as many page links as the container allows, with no CSS breakpoints.

```bash
npm install react-responsive-pagination
```

- React 19, 18, 17 and ^16.8, TypeScript types included, ESM only
- Controlled: `current`, `total` and `onPageChange` are the required props
- Ships no styles: use one of the included themes, or style it with Tailwind, Bootstrap or custom CSS

**Pages**

- [Installation & Compatibility](/installation-compatibility) - install, a minimal example, integration notes (Next.js, URL based paging)
- [Props Reference](/props) - every prop with its type

- [FAQ](/faq) - whether it fits, auto sizing, very narrow widths, server side rendering, ESM only
